# AXON AGENT

مساحة محادثة واحدة يجيب فيها Claude وChatGPT على سؤالك في نفس الوقت، ثم يقرأ كل واحد إجابة الآخر ويصحّحها، كتابةً أو صوتاً.

## التشغيل على Render (موصى به)
OpenAI ترفض الطلبات المباشرة من صفحات مثل GitHub Pages، لذلك يأتي AXON مع خادم صغير (`server.js`) يمرر الطلبات.

1. في Render: **New → Blueprint**، واختر هذا المستودع (يقرأ `render.yaml` تلقائياً).
2. بعد اكتمال النشر افتح الرابط، ثم ⚙ الإعدادات، والصق مفتاحي API، واضغط «فحص الاتصال».

## الخصوصية
- المفاتيح تُكتب وتُحفظ في متصفحك فقط، وتُرسل مع كل طلب. الخادم لا يخزنها ولا يسجلها.
- الخادم يمرر فقط مسارات المحادثة والصوت وفحص الاتصال إلى OpenAI وAnthropic.
- لا يحتوي هذا المستودع أي مفتاح أو بيانات خاصة.
